# CoffeeBoost

Steam Game Idler dashboard — a modern web interface for managing Steam accounts and accumulating game hours.

## Features

- Dark, coffee-themed dashboard interface
- Account management with real-time uptime tracking
- Support for Email Guard and Mobile 2FA authentication
- Game selection with custom App ID support
- Live Steam server connection status
- Responsive design for desktop and mobile

## Getting Started

This is a static site. Serve `index.html` with any web server or deploy directly to Netlify.
